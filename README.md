# Сайт УралСМТ — перегон автотранспорта и спецтехники

Новый сайт ООО «УралСибМегаТранс» (uralsmt.ru). Дизайн сделан по мотивам unitedcarriers.com: тёмный первый экран с интерактивным глобусом и маршрутами, крупная типографика, анимации при прокрутке. Контент перенесён со старого сайта uralsmt.ru.

Сайт статический (HTML + CSS + JS), сборка не нужна.

## Структура

```
index.html            — главная страница (все разделы)
policy.html           — политика обработки персональных данных
send.php              — обработчик заявок (отправка на почту через mail())
assets/css/style.css  — стили
assets/js/config.js   — настройки: адрес обработчика форм, e-mail, телефон
assets/js/main.js     — меню, анимации, тарифы, калькулятор, галерея, формы
assets/js/globe.js    — глобус с маршрутами (canvas)
assets/js/land-dots.js — точки суши для глобуса (сгенерированы из world-atlas)
assets/img/           — фотографии со старого сайта (WebP)
```

## Разделы главной

Первый экран с глобусом → О компании и цифры → Услуги (7 направлений) → Тарифы перегона и калькулятор → Этапы работы → Перевозка тралом → Монтаж и крепление ЗИП → Отключение AdBlue → Почему мы → Наши работы (галерея) → Марки техники → Водителям → Вопросы и ответы → Контакты и форма.

## Запуск локально

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

## Заявки с сайта

- На обычном хостинге с PHP (Beget, Timeweb, REG.RU и т. п.) формы отправляются через `send.php` на `uralsmt74@yandex.ru`. Адрес получателя меняется в переменной `$to` в `send.php`.
- Если PHP нет (например, GitHub Pages), форма откроет почтовую программу посетителя с готовым письмом. Чтобы принимать заявки без PHP, укажите в `assets/js/config.js` в `formEndpoint` адрес любого сервиса форм, который отвечает JSON `{"ok": true}`.

## Что поменять

- **Тарифы** — объект `TARIFFS` в `assets/js/main.js` (карточки тарифов и калькулятор берут цены оттуда).
- **Цены на ЗИП** — блок `.price-list` в `index.html`.
- **Маршруты на глобусе** — массив `CITIES` в `assets/js/globe.js`.
- **Фото в галерее** — блок `#works-track` в `index.html`.

# Сайт УралСМТ — перегон автотранспорта и спецтехники

Сайт ООО «УралСибМегаТранс» (uralsmt.ru). Дизайн сделан по мотивам unitedcarriers.com: тёмный первый экран с интерактивным глобусом и маршрутами, крупная типографика, анимации при прокрутке, переходы между страницами со шторкой. Контент перенесён со старого сайта uralsmt.ru.

Сайт статический (HTML + CSS + JS). Готовые страницы лежат в корне репозитория — их можно сразу выкладывать на хостинг.

## Как редактировать

Страницы собираются из исходников в `src/`, чтобы шапку, подвал и общие блоки не приходилось править в 12 файлах.

```
src/pages/      — содержимое каждой страницы (в начале файла — заголовок и описание)
src/partials/   — общие блоки: layout (шапка, подвал), cta (форма), process, why, brands, calc…
build.py        — сборка: python3 build.py
```

После правок в `src/` запустите `python3 build.py` — HTML-файлы в корне обновятся. Править HTML в корне напрямую не нужно: при следующей сборке изменения перезапишутся.

Остальное:

- `assets/css/style.css` — стили
- `assets/js/main.js` — меню, анимации, тарифы, калькулятор, галерея, формы
- `assets/js/transitions.js` — переходы между страницами (шторка)
- `assets/js/globe.js`, `assets/js/land-dots.js` — глобус на главной
- `assets/js/config.js` — адрес обработчика форм, e-mail, телефон
- `assets/img/` — фотографии со старого сайта (WebP)

Что где менять:

- **Тарифы** — объект `TARIFFS` в `assets/js/main.js` (карточки и калькулятор берут цены оттуда).
- **Цены на ЗИП** — блок `.price-list` в `src/pages/zip.html` и `src/pages/tariffs.html`.
- **Маршруты на глобусе** — массив `CITIES` в `assets/js/globe.js`.
- **Фото в галерее** — `src/pages/works.html` (главная карусель — `src/pages/index.html`).
- **Подписи на шторке перехода** — объект `TITLES` в `assets/js/transitions.js`.

## Запуск локально

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

## Заявки с сайта

- На хостинге с PHP (Beget, Timeweb, REG.RU и т. п.) формы отправляются через `send.php` на `uralsmt74@yandex.ru`. Адрес получателя — переменная `$to` в `send.php`.
- Без PHP (например, на GitHub Pages) форма откроет почтовую программу посетителя с готовым письмом. Чтобы принимать заявки без PHP, укажите в `assets/js/config.js` в `formEndpoint` адрес сервиса форм, который отвечает JSON `{"ok": true}`.
